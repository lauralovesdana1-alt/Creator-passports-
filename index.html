# GitHub Creator Passports A small developer directory app for creator identities and GitHub-linked passports. ## Features - Unique creator IDs - Developer directory search - Create new creator passports - Verified/unverified badge state - Persistent backend storage with Express - Local storage fallback for browser-only use ## Run locally 1. Install dependencies: ```bash npm install ``` 2. Start the app: ```bash npm start ``` 3. Open: ```bash http://localhost:3000 ``` ## Files - `index.html` — UI shell - `styles.css` — styling - `app.js` — UI logic and fetch integration - `server.js` — Express backend and API - `data/creators.json` — saved creator data ## API - `GET /api/creators` — list creators - `POST /api/creators` — add a new creator - `POST /api/reset` — restore demo data ## Notes This is a solid MVP foundation and is ready to extend with GitHub OAuth, real authentication, and a database-backed profile system.
